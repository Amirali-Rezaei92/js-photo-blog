# 📸 ESTATE '24 – Galleria Fotografica in stile Polaroid

Un progetto front‑end che mostra una galleria di foto in stile Polaroid, con immagini caricate tramite Fetch API e apertura in modalità ingrandita (modal) al click.

## 🚀 Funzionalità
- Caricamento dinamico delle immagini da API esterna  
- Card generate in JavaScript  
- Layout responsive (1–2–3 colonne)  
- Stile Polaroid con pin grafico  
- Apertura della foto in modalità full‑view tramite modal  
- Chiusura del modal con un click sull’overlay  

## 🧩 Tecnologie utilizzate
HTML5, CSS3, JavaScript (ES6), Fetch API, Google Fonts, Bootstrap
